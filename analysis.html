        How to equip trackers

        The stats API can only see the trackers on your legends' banners, so more trackers = a more complete analysis.

        Steps (in Apex)

        1. From the lobby, open the Legends tab.
        2. Click the legend you want to track (start with your main).
        3. Open Banner, then the Trackers section. Each legend has 3 tracker slots.
        4. Click a slot and pick a tracker, e.g. Kills, Damage, Games Played. Most trackers start from your lifetime total once equipped.
        5. Select that legend in the lobby. The API reads the banner of the legend you have selected.
        6. Wait a minute, then press ↻ Refresh on the dashboard (or reload this page).
        7. Repeat for each legend you play. The API remembers each legend's trackers once it has seen them.

        You only have 3 slots per legend, so you can swap trackers over time: the API keeps the last value it saw for each one.

        What to equip for this page

          Best 3 for your main: Games Played, Kills, Damage. Then rotate in Knockdowns, Revives and Wins.
